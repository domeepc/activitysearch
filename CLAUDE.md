## Architecture

**ActivitySearch** is an activity booking platform. The frontend is Next.js 16 (App Router) + React 19 + TypeScript. The backend is entirely **Convex** — a real-time database with serverless functions, no traditional REST API. Auth is **Clerk**, payments are **Stripe**; online presence is a Convex heartbeat (`convex/presence.ts`).

### Data flow

- All database reads/writes go through Convex queries/mutations/actions in `convex/`
- The frontend uses the Convex React client (`useQuery`, `useMutation`) — no fetch calls to your own API
- Clerk authenticates users; a webhook syncs them to Convex on sign-up (`convex/http.ts` → `clerk-users-webhook`)
- Stripe webhooks also hit Convex HTTP actions (`stripe-webhook`, `stripe/payment-intent-confirmed`)

### Convex backend (`convex/`)

- `schema.ts` — single source of truth for all database tables
- `http.ts` — HTTP router for external webhooks (Clerk, Stripe)
- Functions are split by domain: `activity.ts`, `reservations.ts`, `messages.ts`, `users.ts`, `quests.ts`, `stripe.ts`, `organisation.ts`, `reviews.ts`, `loyalty.ts`, `presence.ts`, `crons.ts`
- `_generated/` is auto-generated by Convex — never edit manually

### Frontend structure

- `app/` — Next.js App Router pages. `(auth)/` group for sign-in/sign-up
- `components/` — organized by domain (`activities/`, `chat/`, `payments/`, `quests/`, `organisation/`, `reservations/`, `ui/`)
- `components/providers/` — all React context providers; the hierarchy in `app/layout.tsx` is: Clerk → Convex → Quest → PostHog → Presence
- `lib/` — utilities, custom hooks (`lib/hooks/`), TypeScript types (`lib/types/`), and route definitions (`lib/routes.ts`)

### Key systems

- **Gamification/Quests**: `convex/quests.ts`, `convex/questLogic.ts`, `convex/gamification.ts`, `lib/gamification/`, `components/quests/`, bootstrapped via `QuestSystemBootstrap`
- **Chat**: End-to-end encrypted (`lib/encryption.ts`), real-time via Convex
- **Payments**: Stripe Connect for organiser payouts; pricing logic in `lib/reservationsPricing.ts`
- **Maps**: MapLibre GL (`react-map-gl/maplibre`) with OpenFreeMap tiles — no API key (`components/ui/map/ActivityMap.tsx`); geocoding in `lib/geocoding.ts`
- **Presence**: `PresenceProvider` sends `presence.heartbeat` every 30s while a tab is visible; `usePresence` treats a user as online if seen in the last 75s
- **Analytics**: PostHog (proxied through `/ingest` rewrites in `next.config.ts`); Sentry for errors

### Environment variables

Required in `.env.local`:
- `NEXT_PUBLIC_CONVEX_URL` / `CONVEX_DEPLOYMENT`
- `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` / `CLERK_SECRET_KEY`
- `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY` (server keys set in Convex env)
- Optional: `NEXT_PUBLIC_MAP_STYLE_LIGHT` / `NEXT_PUBLIC_MAP_STYLE_DARK` to override the map style URLs
- `NEXT_PUBLIC_POSTHOG_KEY` / `NEXT_PUBLIC_POSTHOG_HOST`
- `NEXT_PUBLIC_SENTRY_DSN`

Convex environment also needs: `CLERK_WEBHOOK_SECRET`, `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`.

### UI components

Uses **shadcn/ui** (new-york style, Tailwind v4, lucide icons). Add components via `npx shadcn@latest add <component>`. Base components live in `components/ui/`.

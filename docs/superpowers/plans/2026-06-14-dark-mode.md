# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add dark mode support with a toggle in both navbars, using `next-themes` and the existing `.dark` CSS variable set.

**Architecture:** `next-themes` `ThemeProvider` wraps the root layout and applies the `.dark` class to `<html>`. A shared `ThemeToggle` component reads/writes the theme via `useTheme()`. CSS hardcodes in `style.css` and `LandingNavbar.tsx` are replaced with CSS variables so they respond to the `.dark` class automatically.

**Tech Stack:** `next-themes`, Tailwind v4 class-based dark variant (`@custom-variant dark (&:is(.dark *))`), lucide-react icons, shadcn/ui Button

### Task 4: Create ThemeToggle component

**Files:**
- Create: `components/ui/ThemeToggle.tsx`

`mounted` guard prevents SSR rendering the icon (server doesn't know the theme). Before mount, render an invisible placeholder of the same size to avoid layout shift.

- [ ] **Step 1: Create the file**

```tsx
"use client";

import { useTheme } from "next-themes";
import { useEffect, useState } from "react";
import { Moon, Sun } from "lucide-react";
import { Button } from "@/components/ui/button";

export function ThemeToggle() {
  const { theme, resolvedTheme, setTheme } = useTheme();
  const [mounted, setMounted] = useState(false);

  useEffect(() => {
    setMounted(true);
  }, []);

  if (!mounted) {
    return <Button variant="ghost" size="icon" className="size-9 opacity-0" aria-hidden />;
  }

  const isDark = resolvedTheme === "dark";

  return (
    <Button
      variant="ghost"
      size="icon"
      className="size-9"
      onClick={() => setTheme(isDark ? "light" : "dark")}
      aria-label={isDark ? "Switch to light mode" : "Switch to dark mode"}
    >
      {isDark ? <Sun className="size-4" /> : <Moon className="size-4" />}
    </Button>
  );
}
```

"use client";

import { useEffect, useState } from "react";
import Link from "next/link";
import Image from "next/image";
import { Button } from "@/components/ui/button";
import { ThemeToggle } from "@/components/ui/ThemeToggle";
import { cn } from "@/lib/utils";

export function LandingNavbar() {
  const [scrolled, setScrolled] = useState(false);

  useEffect(() => {
    const onScroll = () => setScrolled(window.scrollY > 10);
    window.addEventListener("scroll", onScroll, { passive: true });
    return () => window.removeEventListener("scroll", onScroll);
  }, []);

  return (
    <header
      className={cn(
        "fixed top-0 left-0 right-0 z-50 transition-all duration-200",
        scrolled ? "bg-background border-b border-border shadow-sm" : "bg-transparent"

          <Image
            src="/full-logo.svg"

            height={30}
            className="hidden md:block"
            priority

          <Image
            src="/mobile-logo.svg"
